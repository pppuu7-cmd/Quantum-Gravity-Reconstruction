# QGR Quantum Completion / Fallback Contract v1

This contract defines testable obligations for a future genuinely quantum QGR candidate; it does not invent that candidate.

Required chain: `microscopic object -> state space -> amplitude/generator/measure -> normalization -> regulator -> regulator removal or extension -> composition/gluing -> causal/physical sector -> observable -> continuum/IR map`.

For each object, `EXPLICIT` means a versioned mathematical definition plus provenance and domain; `MISSING` means no such object exists; `BLOCKED` is required when downstream evaluation cannot proceed because a required object/evidence is missing; `FAIL` requires an explicit contradiction of a frozen criterion, never mere absence.

A structural blocker forbids heavy compute. A future record may legitimately remain `BLOCKED_MISSING_QUANTUM_MEASURE`, `BLOCKED_REGULATOR_REMOVAL`, `BLOCKED_UV_IR_MAP`, or `BLOCKED_NORMALIZED_OBSERVABLE` while programme infrastructure remains complete.
