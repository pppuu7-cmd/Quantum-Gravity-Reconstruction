## Exact results

### 1. Additive primitive event valuation

Let `J_n` denote the source associated with `n=1..6` equivalent primitive distinct-pair events. Impose:
- empty insertion has zero source;
- S4-equivalent primitive events have the same source unit;
- admissible disjoint/serial primitive composition is additive: `J_{a+b}=J_a+J_b`.

The exact constraint matrix has rank 5 on six source values, hence nullity 1. Its canonical ray is

`(J_1,...,J_6) proportional to (1,2,3,4,5,6)`.

Therefore, within this frozen additive primitive class,

`J(n)=beta*n`.

The law **shape** is derived; the overall physical conversion `beta` is not.

### 2. Multiplicative composition control

If instead a multiplicative character is considered, `A_{n+m}=A_n A_m` with `A_0=1` fixes the shape `A_n=a^n` but leaves the generator `a` free. Composition alone therefore does not provide an absolute physical normalization in either additive or multiplicative form.

### 3. Prefix/history normalization

The existing B4 prefix law gives exact conditional probabilities

`1/4, 1/3, 1/2, 1`

and full history probability `1/24`. These are dimensionless combinatorial branch weights and have zero authority on the physical source scale `beta`.

### 4. Boundary coboundary / path independence

For an S4-invariant rank-shell boundary potential `phi_r`, path independence is automatic. Requiring a homogeneous primitive insertion reduces the shell values to

`phi_r = r*d`,

again leaving one overall scale `d`.

### 5. Composition ratios

The derived primitive step counts are:
- one B4 diagonal: 4;
- face-overlap global region: 5;
- two true serial B4 blocks: 8.

For `J(n)=beta*n`, their physical source ratios are therefore exactly

`4:5:8`,

or normalized to the B4 source:

`1 : 5/4 : 2`.

The corresponding combinatorial path counts `24, 60, 576` are separate dimensionless normalization data and do not fix `beta`.
