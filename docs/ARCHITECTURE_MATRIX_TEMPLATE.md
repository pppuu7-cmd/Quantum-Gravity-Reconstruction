# QGR-G0 Architecture Matrix Template

Use this template in Iter002 before promoting any physical ansatz.

## Fixed scoring dimensions

Each architecture receives a score from 0 to 4 on each dimension. Scores must be justified by explicit objects or derivations, not aesthetics.

- **O — Ontology clarity:** microscopic object/state space is explicit.
- **C — Composition closure:** gluing/composition is mathematically defined and internally consistent.
- **K — Causal closure:** causal primitive and admissibility rule are intrinsic and testable.
- **F — Finite-definition rigidity:** normalization/regulator/extension data are fixed prospectively with low residual freedom.
- **G — Geometry emergence:** nontrivial geometric observables can be constructed from microscopic variables.
- **L — Lorentzian/GR route:** plausible controlled route to 4D Lorentzian GR exists without inserting GR by definition.
- **S — Same-realization continuity:** UV-to-IR objects and parameters can plausibly retain identity.
- **R — Rigidity/falsifiability:** low free-function burden and strong cheap falsifiers.
- **Q — Quantum consistency:** state/probability/unitarity or framework-appropriate replacement is explicit.
- **E — End-to-end observability:** normalized operational observable appears constructible.

Maximum preliminary score: 40. The total score is secondary to fatal-gate status.

## Fatal gates

A branch cannot be promoted if any of the following is already established:

- `FG1`: composition is inconsistent or undefined at the exact physical object level;
- `FG2`: dynamics require effectively arbitrary free functions with no fixing principle;
- `FG3`: no mechanism exists for finite/normalized physical quantities;
- `FG4`: no nontrivial route from microscopic variables to geometry is identifiable;
- `FG5`: Lorentzian/GR recovery requires switching to a different realization;
- `FG6`: quantum/probabilistic consistency is contradicted in the intended domain.

A branch may remain `BLOCKED` if a fatal gate cannot yet be evaluated.

## Branch-generation rule

Generate at least four genuinely distinct architecture classes. Distinction must concern the fundamental object and/or law of dynamics, not merely parameter values.

Possible conceptual axes to explore without presupposing a winner include:

- geometry-first vs relation/information-first microscopic variables;
- fixed kinematics + constrained dynamics vs jointly reconstructed kinematics/dynamics;
- local compositional amplitudes vs globally constrained histories;
- discrete microscopic support vs algebraic/continuum primitive;
- fundamental causal order vs emergent causal order.

These axes are prompts, not endorsed models.

## Promotion criterion

A provisional winner may be promoted to R3 only if:

1. no fatal gate is triggered;
2. at least three prospective cheap kill tests are passed;
3. residual free functions/coefficients are explicitly counted or bounded;
4. the winning rationale does not rely on changing the scoring after outcomes are known;
5. the branch offers a concrete mechanism for both finite definition and same-realization UV-to-IR transport.

If no branch qualifies, Iter002 ends with `NO_PROMOTION` and the ontology search continues.
