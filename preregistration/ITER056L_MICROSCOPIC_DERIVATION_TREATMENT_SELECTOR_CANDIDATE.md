# ITER056L — MICROSCOPIC-DERIVATION PHYSICAL TREATMENT SELECTOR CANDIDATE

## GATE_ID
`ITER056L-MICROSCOPIC-DERIVATION-TREATMENT-SELECTOR-CANDIDATE`

## STATUS BEFORE EVIDENCE
Prospective candidate-principle definition only. This file does **not** authorize any Weyl3 dynamical treatment.

## MOTIVATION
QGR is a reconstruction program whose intended continuum dynamics should be induced by its microscopic history/amplitude/measure structure rather than selected after the fact by whichever continuum PDE is easiest to solve. The candidate selector is therefore deliberately treatment-blind: compare admissible continuum treatments against the same regulator-controlled microscopic observable map and let the microscopic-to-continuum relation select, fail to select, or reject all candidates.

This motivation is independent of fast-mode/ghost removal, mathematical convenience, green CI, or preference for order reduction.

## FROZEN CANDIDATE PRINCIPLE S_micro
Let `T` denote a fully specified candidate Weyl3 dynamical treatment (for example exact higher-derivative, finite-order order-reduced at declared N and validity domain, another resummed treatment, or any future explicit treatment).

`S_micro(T)` is satisfied only if there exists a **QGR-owned, source-faithful, regulator-controlled microscopic→continuum map** that sends the same microscopic history/amplitude/measure data to normalized continuum observables generated by `T`, with:

1. the microscopic amplitude/measure object defined independently of `T`;
2. a regulator/refinement variable and declared removal/continuum procedure;
3. normalization fixed relationally or otherwise source-faithfully without setting `beta=1`;
4. a common overlap observable defined on both microscopic and continuum sides;
5. symbolic `c6` preserved unless the map itself derives/fixes it;
6. a declared convergence/equivalence tolerance or exact identity established before comparing treatments;
7. no treatment-dependent fitted weights, contours, counterterms, initial-data filters, or phase conventions introduced solely to make a candidate pass;
8. at least one discriminating observable/response for which inequivalent treatments can in principle disagree.

## SELECTION RULE
- If exactly one treatment equivalence class satisfies `S_micro`, that class is selected within the tested domain.
- If more than one inequivalent class satisfies it, the selector is non-unique and no physical treatment is authorized.
- If none satisfies it, no tested treatment is authorized.
- If the required microscopic→continuum object is not defined or regulator removal is unavailable, the gate is `BLOCKED_OBJECT_DEFINITION`, not a vote for order reduction or exact dynamics.

## FALSIFIERS
The candidate principle is falsified as an executable QGR selector for the present repository state if any mandatory object is absent: source-faithful microscopic measure/amplitude, regulator-removal/refinement map, normalized common observable, or treatment-independent matching rule.

A future implementation of `S_micro` is falsified for uniqueness if two inequivalent treatments reproduce all preregistered discriminating observables within the frozen equivalence relation/tolerance.

## CURRENT-GATE QUESTION
Without using treatment-dependent downstream outcomes, does the pre-existing QGR repository already contain all mandatory objects needed to execute `S_micro` at least on one nontrivial Weyl3-sensitive overlap observable?

## PASS
`PASS_SCOPED_ITER056L_MICROSCOPIC_DERIVATION_SELECTOR_EXECUTABLE_ON_FROZEN_OVERLAP` only if every mandatory object above is pinned to source authority and at least one nontrivial Weyl3-sensitive common observable can be compared without adding treatment-specific rescue information.

## BLOCKED
`BLOCKED_OBJECT_DEFINITION_ITER056L_MICROSCOPIC_DERIVATION_SELECTOR_NOT_YET_EXECUTABLE` if one or more mandatory objects are missing. Missing objects must be named exactly.

## INVALID
`INVALID_PROVENANCE` if treatment-dependent evidence is inspected before this preregistration and then used to modify the selector; `INVALID_IMPLEMENTATION` if new fitted rescue structure is introduced inside this gate.

## CLAIM CEILING
Even PASS would establish only that a treatment-blind microscopic selector is executable on a scoped overlap. It would not by itself establish that a unique treatment wins, that QGR is correct, that `c6` is fixed, that the theory is unitary/UV complete, or that experiment confirms it.
